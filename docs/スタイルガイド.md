# SLEEP CITY 2.0 スタイルガイド

Tailwind CSS に関するプロジェクト共通のスタイルルール。
SLEEP CITY はダッシュボード型 UI（City Map + KPI + Timeline + Causal Graph）であり、
画面全体を高さいっぱいに使うレイアウトと、Agent 状態を表す色の一貫性が特に重要になる。

## ビューポート高さ: `dvh` を使う

### ルール

- `h-screen` / `min-h-screen` は**使用禁止**
- 代わりに `h-dvh` / `min-h-dvh` を使用する
- `calc()` 内の `100vh` も `100dvh` に置き換える

### 理由

モバイルブラウザ（iOS Safari, Android Chrome 等）では、アドレスバーやナビゲーションバーの表示/非表示により、
`100vh` が実際の可視領域と一致しない。`dvh`（Dynamic Viewport Height）を使うことで、ブラウザ UI の状態に応じた
正確な高さを取得できるため。SLEEP CITY のメイン画面は City Map と KPI パネルを画面高に合わせて分割するため、
ここがずれると Map がスクロール領域からはみ出し、デモ時の見栄えが崩れる。

### ビューポート単位の比較

| CSS 単位 | Tailwind クラス | 説明 |
|----------|----------------|------|
| `100vh` | `h-screen` | ブラウザ UI を含む固定サイズ。モバイルで問題になりやすい |
| `100dvh` | `h-dvh` | ブラウザ UI の表示/非表示に応じて動的に変化（推奨） |
| `100svh` | `h-svh` | ブラウザ UI が表示された状態の最小ビューポート |
| `100lvh` | `h-lvh` | ブラウザ UI が非表示の状態の最大ビューポート |

### 具体例

```tsx
// NG
<div className="min-h-screen bg-gray-50">
<div className="h-screen md:h-[calc(100vh-96px)]">

// OK
<div className="min-h-dvh bg-background">
<div className="h-dvh md:h-[calc(100dvh-96px)]">
```

### ブラウザサポート / 備考

`dvh` は主要ブラウザで広くサポート済み（Chrome 108+, Safari 15.4+, Firefox 101+）。
古い環境への対応が必要な場合のみフォールバックを検討すること。

## カラーパレット構成

### ルール
- ベースカラーは `bg-background` / `text-foreground` / `bg-primary` など shadcn/ui のセマンティックトークンを使用する
- 直に `#hex` 値を `className="text-[#333]"` のように指定しないこと
- **Agent の睡眠状態を表す色は必ず専用トークン経由で参照する。** コンポーネント側で個別に色を決めない

### 理由
ダークモード対応やテーマ変更時の保守性を高めるため。
加えて SLEEP CITY では同じ睡眠状態が City Map・Agent Detail・Event Timeline・Causal Graph・Recharts の凡例と
5 箇所以上に登場するため、色定義が散らばると「Map では黄色、グラフでは橙」といった不整合が即座に発生する。

### 睡眠状態カラートークン

`globals.css` に CSS 変数として定義し、Tailwind のユーティリティから参照する。

| 状態 | トークン | 用途 |
|---|---|---|
| Normal | `--color-sleep-normal` | Sleep Debt < 1h |
| Tired | `--color-sleep-tired` | 1h 以上 2h 未満 |
| Sleep Deprived | `--color-sleep-deprived` | 2h 以上 5h 未満 |
| Severe Sleep Deprived | `--color-sleep-severe` | 5h 以上 |
| Accident / Transmission 強調 | `--color-alert` | 事故・伝播エッジのハイライト |

Canvas / SVG で City Map を描画する場合も、色は `getComputedStyle` 等で CSS 変数から取得し、
描画コード内にリテラルの色を書かない。

### 具体例
```tsx
// NG
<div className="bg-[#f59e0b]" />
<span style={{ color: "#ef4444" }} />

// OK
<div className="bg-sleep-tired" />
<span className="text-sleep-severe" />
```

## 密度の高いダッシュボードのレイアウト

### ルール
- パネル分割は Flexbox / Grid + `min-h-0` を併用し、内部スクロールは各パネルに閉じる
- 数値 KPI には `tabular-nums` を付与し、Tick 更新のたびに桁幅が揺れないようにする
- 300〜500 Agent を描画する City Map は DOM 要素で 1 Agent 1 div とせず、Canvas または集約表示を用いる

### 理由
Watch Mode では 8x 速度で Tick が進み、KPI とマーカーが高頻度で再描画される。
レイアウトが Tick ごとに揺れると視認性が落ち、CLS も悪化するため。

### 具体例
```tsx
// NG（数値幅が揺れる / パネルが伸び続ける）
<div className="flex flex-col">
  <span className="font-mono">{rs}</span>

// OK
<div className="flex min-h-0 flex-col overflow-hidden">
  <span className="font-mono tabular-nums">{rs.toFixed(2)}</span>
```
