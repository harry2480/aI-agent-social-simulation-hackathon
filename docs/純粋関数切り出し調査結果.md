# SLEEP CITY 2.0 純粋関数切り出し・テスト追加候補 調査結果

## 概要

`apps/webapp/src/` と `apps/webapp/scripts/` 配下の全モジュールを調査し、コンポーネント・Hook・
Route Handler・Domain Service 内に埋め込まれた純粋関数（テスト可能なロジック）の候補を洗い出した。

本プロジェクトは `src/frontend/lib/` に表示ロジックを切り出す方針が既に確立しており、
そこに置かれた 9 ファイルはすべて Unit テスト済みである。一方で以下の 3 つの層に穴が残っている。

1. **Domain Service の直接テストが無い** — Simulation Engine 経由の間接テストのみで、
   閾値や倍率などの物理法則を単体で固定できていない
2. **描画・集計ロジックがコンポーネント内に閉じている** — Canvas 座標計算、Chart 系列変換、
   KPI 行の組み立てなど
3. **scripts/ に同一実装が 2 箇所ある** — `run-experiment.ts` と `compare-ai-models.ts` で
   集計関数がまるごと重複している

### 調査範囲

| 担当 / 領域 | 対象ディレクトリ |
|---|---|
| Domain（物理法則・モデル） | `src/backend/domain/` |
| Application / Presentation | `src/backend/application/`, `src/backend/presentation/` |
| Infrastructure | `src/backend/infrastructure/` |
| Frontend（画面・Hook・ページ） | `src/frontend/`, `src/app/` |

## 推奨実装順序

### Phase 1: テスト追加のみ（コード変更なし）
- Tier 1 の項目（#1〜#10）
- 物理法則の閾値・倍率をテストで固定する。Domain Service の直接テストが無い現状では、
  Simulation Engine のリファクタで挙動が変わっても気づけない

### Phase 2: 重複の解消（#11・#12・#22・#40）
- 実装が 2 箇所にある状態の解消を優先する。片方だけ直す事故を止められる

### Phase 3: 小規模リファクタ+テスト
- Tier 2 の残り（#13〜#21・#23）

### Phase 4: バックエンドprivate関数のexport化+テスト
- Tier 4 の項目（#28〜#37）
- `buildRelationships`（#30）は Cascade の伝播路そのものなので優先度が高い

### Phase 5: クライアントロジック切り出し・サーバー専用ロジック
- Tier 5（#38・#39）と Tier 3（#24〜#27）

## 対象外と判断したもの

- `src/frontend/components/ui/` — shadcn/ui 生成コンポーネント
- `prisma/generated/` — Prisma 生成コード
- `domain/models/result.model.ts` / `domain/models/metrics.model.ts` — 型定義のみで実行ロジックを持たない
- `presentation/composition/*.composition.ts` — DI 組み立て（`decision.composition` / `watch-mode-engine.composition` は既にテスト済み）
- React Component の純粋な JSX レンダリング部分（`run-table.tsx` / `experiment-list.tsx` など、
  ロジックは既に `frontend/lib/` へ切り出し済みで表の描画しか残っていないもの）
- `process.env` に依存する実行環境設定（`isDatabaseConfigured` / `resolveAiModelName`）
- 既にテスト済みのファイル:
  - `frontend/lib/` 全 9 ファイル
  - `domain/models/` の agent / causal-edge / city / experiment-config / simulation-clock / simulation-event / sleep-state
  - `domain/services/` の cascade / causal-graph / reproduction-number / seeded-random / simulation-engine / sleep-transmission
  - `infrastructure/adapters/` 全 4 ファイル、`application/usecases/` 全 3 ファイル
